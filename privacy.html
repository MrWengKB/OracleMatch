隐私政策

甲骨文配对（OracleMatch）· 生效日期：2026 年 11 月 26 日

简要说明

甲骨文配对是一个给小朋友认识甲骨文的配对游戏。我们不收集、不储存、也不分享任何个人信息。

我们不收集的资料

  • 不需要注册或登录，没有帐号。
  • 不收集姓名、电子邮件、电话、位置、照片、联系人或设备识别码。
  • 没有广告，没有应用内购买，没有统计分析或追踪工具。

保存在设备上的资料

游戏会在设备本机记住上次选择的年级、课次、字数、翻翻乐开关和自定义字表，方便下次打开时使用。这些资料只保存在设备上，不会上传。卸载 App 或清除浏览器资料就会删除。

网络

  • Google Play 版本不使用网络，游戏完全离线运行。
  • 从 GitHub 下载的 APK 版本在启动时会访问 GitHub（api.github.com）查询有没有新版本，只读取公开的版本信息，不发送任何个人资料。
  • 网页版由 GitHub Pages 提供，GitHub 作为网站服务商可能会按其隐私政策记录一般的访问日志。

儿童隐私

本游戏适合儿童使用。因为我们不收集任何个人信息，所以也不会收集儿童的个人信息。

政策更新

如果本政策有改动，会更新本页面和上面的生效日期。

联系我们

有任何问题，请在 GitHub Issues 留言。

Privacy Policy

OracleMatch · Effective date: 26 November 2026

OracleMatch is a matching game that helps children learn oracle bone script. We do not collect, store or share any personal information.

  • No account, sign-up or login.
  • No names, email addresses, phone numbers, location, photos, contacts or device identifiers are collected.
  • No ads, no in-app purchases, no analytics or tracking.
  • Game settings (grade, lesson, card count, flip mode, custom character list) are saved only on the device and never uploaded.
  • The Google Play version does not use the network and works fully offline. The APK from GitHub only checks GitHub (api.github.com) for a newer version and sends no personal data.
  • The game is suitable for children. Since no personal information is collected, none is collected from children.

Questions: please open an issue at GitHub Issues.
